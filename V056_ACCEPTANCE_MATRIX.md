## States

| state | meaning |
|---|---|
| **clean** (`clean`) | ordinary content, fully readable |
| **finding** (`finding`) | a pattern fires, fully readable |
| **incomplete, no finding** (`incomplete_clean`) | part unread, nothing found in the rest |
| **incomplete + finding** (`incomplete_finding`) | a finding AND part of the input unread |
| **unreadable** (`unreadable`) | exists, cannot be opened (mode 000) |
| **missing** (`missing`) | path does not exist |
| **missing decoder** (`missing_dependency`) | readable media, no decoder installed |
| **truncated + finding** (`truncated_finding`) | over the 1 MiB cap, finding in the read part |
| **corrupt (parser fails)** (`corrupt_parser_fail`) | readable bytes whose format parser gives up |
| **not a regular file** (`nonregular`) | FIFO/socket/device/directory at the input path |
| **bytes do not decode** (`undecodable`) | a byte stream that is not valid UTF-8 |
| **empty** (`empty`) | a VALID input of this format that legitimately carries no content (0-byte text file, blank image, silent audio) -- read in full, nothing there |
| **finding in a later component** (`later_component`) | a multi-frame GIF/TIFF or multi-page document whose finding lives after the first component |
| **byte-valued metadata** (`byte_metadata`) | embedded text carried as BYTES needing its field's own encoding (EXIF XP*/UserComment, GIF comment) |
| **external converter failed** (`converter_failed`) | a helper process (ffmpeg) exits nonzero or writes nothing, so a component never became text |

| surface | state | note |
|---|---|---|
| CLI `scan --repo` | `truncated_finding` | SURFACE DIVERGENCE, recorded not fixed.
