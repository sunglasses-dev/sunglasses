# Roadmap

Updated 2026-10-29. Dates are intent, not promises.

## What does not change

| | |
|---|---|
| License | MIT. Released code keeps its MIT license. |
| Community engine | Scanner, CLI, MCP server, firewall hook and every public pattern stay in this repository. |
| Promise | The maintained MIT Community engine, every right already released, honest fixes and independent local verification will not be degraded to create a paid tier. |
| Removal | Nothing you have today is removed, gated or relicensed. |
