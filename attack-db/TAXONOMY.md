# Attack categories and the public frameworks they sit under

Every finding's `category` maps to entries in three published lists. `sunglasses scan --json` carries them on each finding as `taxonomy`, and SARIF output carries them as `taxonomies` with a `relationships` entry on each rule.

This is a category-level mapping. It says which headings an attack of this kind is discussed under, not that one finding is a confirmed instance of a technique. A category can touch more than one heading, and some headings are a loose fit; the closest entries that exist in each list were chosen and no identifier is invented. It is data that annotates output. It is never read when the scanner decides.

Generated from [`sunglasses/taxonomy.py`](../sunglasses/taxonomy.py) by `scripts/export_taxonomy_to_attack_db.py`. Do not edit by hand.
